# 明代历史调研报告

调研问题：明代内阁是否等同于宰相？

洪武十三年（1380），朱元璋在胡惟庸案后废除中书省和丞相，将政务分归六部。永乐时期，解缙等入直文渊阁、参与机务，但《明史》记载阁臣“不得专制诸司”。此后阁臣地位逐步提高，票拟成为影响政务的重要途径；嘉靖时严嵩权势显赫，甚至压制六部。不过，票拟仍须经批红方能施行，内阁没有恢复旧丞相的制度地位。因此，不能把内阁简单视为宰相机构：它在实际政治中可能权势很大，却仍受皇权约束，体现了明代制度安排与实际权力的差别。
