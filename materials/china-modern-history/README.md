# 中国近代史教材与教学资料包

本资料包供历史课备课与学生阅读使用，以1840—1949年为主体，必要时回溯鸦片战争前的背景。默认面向高中进阶至大学入门；这是备课假定，并非课程已确定的学段。建议以《中国近代史》第二版上下册为主教材，用史料讨论连接政治、经济、社会、文化与国际关系。

## 三种阅读路径

- **基础路径**：先读单元导读和年表，每次精读一段史料；已有高中教材的学生，可按同名主题对照阅读。暂不要求读完整部大学教材。
- **大学入门路径**：以T01、T02为主教材，每单元读指定章，再完成一次史料分析。希望一本书覆盖全程的读者，可选T03。
- **教师与进阶路径**：用T06、T07扩展解释角度，用T05学习史料方法，再检索R03、R04中的原始文献。

## 材料性质

目录收集的是可追溯的书目信息和合法获取入口，商业教材全文未收录。本地可直接使用的材料是编制的导读、研读卡、年表和教学建议；其中引文明确标注，中文译意也与原文分开。这些导读是辅助讲义，不是出版社审定教材。

书目、网页介绍和所用史料片段核验于2026年10月4日；没有通读所列全部书籍，也没有逐项测试数据库内的文献或课程视频。具体范围见核验说明。所有阅读时长、教学次序、难度等级及讨论题均为本课程包的教学建议。

课堂练习仅供教学选择，本次没有创建或登记课程作业。
